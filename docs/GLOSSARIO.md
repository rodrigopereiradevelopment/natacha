# GLOSSARIO

## A

Agente — Sistema que recebe objetivos, escolhe ferramentas e executa tarefas.
Atenção (Self-Attention) — Mecanismo do Transformer que permite focar em partes importantes do texto.
Ativacao — Funcao que decide se um neuronio "dispara" (ex: ReLU, Sigmoid).

## B

Backpropagation — Algoritmo que propaga o erro para tras, ajustando pesos.
Bias — Valor adicionado a soma ponderada de um neuronio.

## C

CUDA — Plataforma NVIDIA para calculos paralelos na GPU.

## D

Dataset — Conjunto de dados para treinar ou testar.
Deep Learning — Area do ML com redes neurais profundas.

## E

Embedding — Representacao vetorial de uma palavra.
Epoca — Uma passagem completa pelo dataset durante treinamento.

## F

Felix — IAgato, companheiro da Natacha.
Feed-Forward — Camada da rede que processa saida da atencao.
Forward Pass — Dados entram, saem previsoes.

## G

Gradiente Descendente — Algoritmo que ajusta pesos para minimizar erro.

## I

IAgato — Categoria inventada por Rodrigo. Agente autonomo que simula gato.
Inferencia — Usar modelo treinado para previsoes.

## L

LLM — Large Language Model (ex: GPT, Natacha futura).
LSTM — Long Short-Term Memory. Tipo de RNN com memoria longa.

## M

MLP — Multilayer Perceptron. Rede neural com camadas ocultas.

## N

Natacha — IA adolescente rebelde construida do zero em C++.
Neuronio — Unidade basica de rede neural.

## P

Perceptron — Neuronio artificial simples.
Peso — Valor que determina importancia de uma entrada.

## R

RNN — Recurrent Neural Network. Processa sequencias.
ReLU — Rectified Linear Unit. Funcao de ativacao: f(x) = max(0, x).

## S

Sigmoid — Funcao que mapeia qualquer valor para entre 0 e 1.
Softmax — Funcao que transforma vetor em probabilidades.
STT — Speech-to-Text (ex: Whisper).

## T

Token — Unidade basica de texto.
Tokenizacao — Dividir texto em tokens.
Transformer — Arquitetura que usa atencao. Base do GPT.
TTS — Text-to-Speech (ex: Piper).

## V

VCS — Virtual Companion System. Modo conversa da Natacha.
Viseme — Forma da boca para um fonema. Usado em lip sync.

## X

XOR — Operacao logica exclusiva. Neuronio sozinho nao aprende — precisa MLP.
