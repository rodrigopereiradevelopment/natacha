1. INTRODUÇÃO

1.1 Propósito

Este documento consolida toda a bibliografia externa do Projeto Natacha: papers científicos, documentação técnica, obras literárias, filosóficas e musicais. É a fonte única de verdade para citações externas.

1.2 Como usar

· Nos outros documentos: em vez de listar referências completas, citar por número entre colchetes [1], [2], etc.
· Na seção "Conexões" de cada documento: listar os números citados.
· No EditeCC: este arquivo é a base para formatação ABNT automática.

Alguns papers listados são preprints ou publicações recentes (2025–2026) cujos DOIs ainda não foram finalizados. Quando aplicável, a referência é marcada com (preprint) ou (no prelo). Isso é prática comum em bibliografias acadêmicas.
